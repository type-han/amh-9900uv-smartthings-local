# 4. 안전과 보안

## 4-1. 보내는 값

드라이버는 **앱에서 실제로 쓰는 값만** 보냅니다 (`driver/src/amh.lua`의 `is_safe`).

| DP | 허용 값 |
|---|---|
| 1, 16, 21, 26, 29, 101 | true / false |
| 13 목표 습도 | 45, 50, … 100 |
| 23 분무 단계 | level_1, level_2, level_3 |
| 19 타이머 | 보내지 않음 |

- 사양 범위 안의 값이라도 앱이 쓰지 않는 조합은 시험하지 않았습니다. 특히 **꺼진 상태에서 다른 DP를 쓰는 것**은 앱이 막는 동작이라 드라이버도 하지 않습니다 (먼저 전원을 켬).
- 직접 tinytuya 등으로 값을 보낼 때도 위 표 밖의 값은 보내지 마세요. 기기가 멈추면 전원 플러그를 뽑았다가 다시 꽂아 보세요.

## 4-2. Local Key 관리

- Local Key가 있으면 **같은 LAN의 누구나 가습기를 제어**할 수 있습니다.
- `secrets/` 폴더(`devices.json`, `tinytuya.json` 등)는 `.gitignore`로 제외되어 있습니다. 포크해서 커밋할 때도 확인하세요.
- 이슈나 로그를 올릴 때 Local Key, Device ID, Tuya IoT Access ID/Secret을 지우세요. 드라이버 로그에는 Local Key가 남지 않습니다.
- SmartThings 기기 설정의 Local Key 입력란은 비밀번호 형식입니다.

## 4-3. 네트워크

- 가습기는 **클라우드 연결을 그대로 유지**합니다. Tuya Smart 앱도 계속 쓸 수 있습니다.
- 드라이버는 허브에서 가습기 6668 포트로만 접속합니다. 인터넷이 끊겨도 동작합니다.
- 게스트 WiFi나 신뢰하지 않는 기기를 같은 LAN에 두지 마세요.

## 4-4. 되돌리기

SmartThings에서 기기를 삭제하고 드라이버를 지우면 끝입니다. 가습기 설정은 바뀌지 않습니다.
Tuya IoT Platform 프로젝트의 앱 계정 연결은 언제든 해제할 수 있습니다.
